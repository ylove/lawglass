# 0004: Node.js 22 minimum

## Context

The original architecture specified Node.js 20 or newer.
The spec Amendments raise the minimum because Node.js 20 reached end-of-life in April 2026.
A single ESM TypeScript package needs a maintained Node runtime and consistent tooling.

## Decision

Require Node.js 22 or newer in package metadata.
Set `.nvmrc` to `22` for local development.
Use strict TypeScript, NodeNext modules, and an ES2023 language target.
The spec requires CI coverage on Node.js 22 and 24.

## Consequences

Node.js 20 is unsupported; users and contributors must upgrade.
Node builds target 22, while the web uses DOM libraries and bundler resolution.
Use an up-to-date Node.js 22 patch release to satisfy current tool engine requirements.
